Strand shelf templates — v35

Includes 14 shelf rows and 313 artwork tiles in Focus and Full-screen variants.

These are shelf layout templates, not a complete account backup. Import your chosen .strand file using Strand's shelf import, TMDB discovery, collection and list sources are retained. Add your own sources to tiles that have no source selected. The Trending Series row is an empty placeholder. Watchlist, sports, TMDB and recommendation rows use the recipient's own settings and may require configuration. No media-server connections are included. TMDB rows browse metadata; playback requires your own configured sources.

All icon and hero addresses point to https://wepiii2.github.io/strand-backgrounds/.

Formatter: copy the name and description templates from Strand-Formatter-v35.txt into the corresponding custom formatter fields. Back up your setup before importing.
